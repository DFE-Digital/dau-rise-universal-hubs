# Overview — Significant Change

## Purpose of this Repository
This repository acts as the technical home for the **Significant Change** analytical, data engineering, and reporting work.

It provides:

- A single source of truth for technical documentation  
- SQL for building and maintaining data assets  
- R code for processing, analysing, and reporting data  
- Links to related tools (pipelines, portals, dashboards)

---

## What This Repository Covers

1. **Policy documentation**
2. **Engagement guide**
3. **Data definitions and table structures**
4. **ETL processes**
5. **Quality assurance and validation rules**
6. **Caveats, risks, and known issues**
7. **Links to other systems and tools**
8. **SQL Tables code**

---

## What It Does NOT Contain

- Shared R functions (see `dauPortalTools`)
- Multi-policy pipelines (see `dau-sssr-pipeline-daily-run`)
- Non-DfE datasets or confidential policy papers
